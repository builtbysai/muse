Who he is

Born 1981, Kumamoto. Associate professor, Dept. of Creative Media Studies, Konan Women's University. Founder/representative director of the Japan Generative Art Foundation (JGAF, est. April 2022 from his Generativemasks earnings; proceeds from the whole artist profit of the 10k drop went to the Processing Foundation and other generative-art orgs). Started coding 2015 as private daily practice ("like practicing a musical instrument"), publishing #dailycoding on Twitter/web since 2019. Codes improvisationally, "as if playing a musical instrument", deliberately injecting "wordplay and humor" as personal essence (Art Blocks bio). Everything is p5.js, published daily, code shared (screenshots of the p5 editor appear inside the posts themselves — the code is part of the frame).

The core engine: THE COMBINATORIAL MASK + THE DAILY INSTRUMENT

Two linked mechanisms:

  1. The combinatorial mask. An algorithm that "combines multiple geometric patterns and shapes into masks with their own

personality" (verse.works). Watchable form: a bilaterally symmetric blob/face silhouette (the container) filled with a dense quilt of small geometric patches — quarter-circles, arcs, squares, triangles — in Wagasa-derived palettes (vermilion, ochre, teal, black, cream). Personality is not drawn; it EMERGES from the combination. The Japan Edition (2022, with curator Junya Yamamine) grounded the patch library in researched traditional Japanese patterns (kimono, folding screens, ukiyo-e) and Japanese color names. Origin story, in his words: "what I've made and what I've seen are naturally expressed in the codes" — his mother has made patchwork quilts for 35+ years, and the masks ARE the quilts rendered in code. Faces read from pure geometry is everywhere in the daily work: a B&W checkerboard whose cells each hold two white dots becomes a field of staring faces (2021-12-18); bloodshot eye grids (2021-12-16); emoji swarms at varying scales (2021-12-15); an emoji-textured rotating WEBGL cube (2024-04-12).

  1. The daily instrument. One idea per day, shipped publicly with the code, never overworked. The practice IS the aesthetic:

short code (tsubuyaki Processing — full sketches in 280 characters — lives in his circle), dated titles, visible editor, tweet-length commitment. He ran #takawo杯 (the Takawo Cup), a community remix contest — the audience modifies his code and feeds it back (Generativemasks shipped CC BY-NC-SA 3.0 precisely so holders could mod and share; holder "junosz" built a mask-modifier app). Watchable behavior: each sketch does ONE thing to exhaustion, then the day ends. The archive is the piece.

Evolution

  • 2015–2018: private instrument. Daily coding with no aim of making "work" — practice as musical exercise.
  • 2019: the diary goes public. Publishes #dailycoding on Twitter/web; comments and code remixes start transforming the practice ("I felt as if I was being transformed by the exchange of various people's ideas and codes mixed in with my own codes").
  • 2020: community organizer. Co-facilitates Processing Community Hangout Japan with Naoto Hieda (May 2020); the #dailycodingchallenge (44 days, a theme per day) runs from the hangout.
  • 2021: maximalist play + the mask. OpenProcessing daily sketches swing between quiet geometry and loud humor (emoji, eyes, neon letters). The mask-combination algorithm crystallizes into Generativemasks: 10k pieces, sold out in 2 hours, proceeds donated. PFP culture meets the daily sketch.
  • 2022: cultural research. Japan Edition with Yamamine — Wagasa patterns, Japanese color research, ukiyo-e shading in video; 3D-printed masks; AR try-on; the math book. Tiny Sketch weekly drops (per the AMA).
  • 2023: the quilt years. Tile combinatorics dominate: Truchet grids, patchwork collages, op-art interference. The mother's quilts, fully internalized as code.
  • 2024: institutional. Patterns of Flow (Feral File/NEORT++), Bright Moments (Marching Resonances interview; "Different azalea" for Bright Moments Venice), CCBT CIVIC CANVAS kids workshops, 25th Japan Media Arts Festival selection member. The daily instrument continues unchanged underneath.

The arc: private exercise → public diary → remix community → cultural artifact (masks) → institution (JGAF, festivals, teaching). What never changes: one idea a day, p5.js, code shared, humor kept in, symmetry + combinatorics as the visual DNA.

How it translates to code (for fly)

The Takawo skeleton — bilateral symmetry + combinatorial patch fill:

// the mask container: symmetric blob/face silhouette
mask = symmetricBlob(seed)              // mirror about vertical axis; "personality" lives here
patches = [quarterArc, arc, square, triangle, dot, stripe]   // the patch library
palette = wagasa(seed)                  // vermilion, ochre, teal, black, cream, indigo
for cell in gridInside(mask):
    patch = pick(patches, seed)         // THE COMBINATION: each cell an independent draw
    draw patch rotated by pick([0,90,180,270])
// faces appear for free: paired dots/arcs inside the symmetric field read as eyes

Rules he never breaks: one idea per day, shipped; symmetry is the default container (mask, target, ring); the patch library stays small and geometric; humor is allowed in as material (emoji, puns, the dashboard laughing at itself); the code is never hidden — showing it is part of the piece; community remixes are a feature, not theft. Watch-only for the motion loops; tap-to-reseed where a new personality belongs (the mask); drag only where the system invites disturbance (the tile field).

What to avoid (his anti-patterns, from the archive)

Never: narrative arcs or composed scenes (the day has no beginning-middle-end); photorealism; decorative gradients as background filler (his gradients are color FUNCTIONS on ribbons, not atmosphere); hiding the mechanism — a Takawo piece always shows its construction; solemnity (the work winks: emoji, puns, the parameter dashboard); breaking symmetry without a reason (his B&W collages stay symmetric for a reason); more than ~5 palette colors in the Wagasa mode.
