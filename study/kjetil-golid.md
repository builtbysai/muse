## Core engine

THE STRUCTURE IS THE WORK AND THE RENDER IS ITS SHADOW: he takes an existing algorithm, data structure, or geometric system, asks the question "What would it look like if ..." some element that is not usually parameterized were made variable, builds the underlying system first, and renders it crudely before refining toward a look that underscores the structure; only when the structure is set does he dress it in a hand-built, systematically chosen palette. The viewer watches a mathematical idea become visible: subdivision, planar symmetry, slant, extrusion, annotation. In his own words (Bright Moments ORBIFOLD interview, June 2023): "I rarely start from a visual image that I try to reproduce through code. On the contrary, my process involves creating a system or structure that serves as the foundation for the entire project. The rendering phase of my process serves as a tool to underscore and accentuate the underlying structure." And: "developing and showcasing the underlying structure of a generative system is the central concern of my artistic practice." On color (same interview): palettes are assembled manually, never left to pure randomness, because "color combinations that are excessively influenced by randomness can compromise the aesthetics of a generative art project." His personal palette library is called Chromatome. Watchable behavior: rigid, precise rectilinear systems that slowly vary one parameterized axis (subdivision depth, slant angle, extrusion height, palette), dressed in bold Bauhaus-adjacent primaries with playful saturated accents, always looking like the inside of an algorithm made physical.

## Observed mechanisms (for prompt grounding)

1. Constrained rectangle subdivision (Archetype): recursive plane division with size constraints + noise; the same subdivision rendered both flat and isometric, with palette/coloring/scene-angle as separate traits.
2. "What would it look like if ...": takes a known algorithm or data structure and parameterizes an element nobody parameterizes (subdivision depth, slant angle, extrusion height, coloring rule); the question is the starting tool, not the image.
3. Isometric laundering of flat data: flat 2D subdivisions are extruded into fake-3D blocks with face shading; depth is a rendering choice, not part of the structure (see also EXPANSE: face color from slant vs light).
4. Hand-built systematic palettes (Chromatome): Bauhaus-adjacent primaries plus playful saturated accents; color is never random, always a chosen set applied to a structure; palette swaps are a trait, not a remix.
5. Planar-symmetry mazes (Orbifold): maze-like rectilinear paths exploring symmetry groups; precision linework, colorful fills, maze as symmetry diagram.
6. Slant as a field (Slants and lerps, Spectrum): rigid cuboids tilted by a spatial field; disorder is a gradient across the frame (dense/calm in one corner, chaotic in the other), not uniform noise.
7. Annotation as texture (2025 blueprints): part numbers, hatched borders, callout labels generated alongside the forms; the spec layer is part of the composition.
8. Curve invasion (Decision Matrix, 2024): rounded arches, cylinders, gear teeth replace the cube; same structural sectioning applied to curved mechanical forms; colorways as named palettes ("Monaco colorway").
9. Controlled destruction (Wildfire, 2026): turbulent erosion texture that breaks the six-year rectilinear rule; useful as a transformation stage, not as the base language.
